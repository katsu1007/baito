ホーム画面に追加する方法・GitHub Pagesへの置き方 ▾

iPhoneのホーム画面に追加（このページを開いている場合）

  1. Safariでこのページを開く
  2. 下の共有ボタン（四角に↑のマーク）を押す
  3. 「ホーム画面に追加」を選んで「追加」

追加後はアプリのように全画面で開けます。記録はこの端末の中（ブラウザの保存領域）に残ります。

GitHub Pagesに置いて自分のURLで使う場合

  1. 下のボタンで、このアプリのHTMLファイルをダウンロードする
  2. GitHubで新しいリポジトリを作り（例：baito-record）、ダウンロードしたファイルを index.html という名前でアップロードする
  3. リポジトリの Settings → Pages で、公開元に「main ブランチ / ルート」を選ぶ
  4. 表示されたURL（https://ユーザー名.github.io/baito-record/）をSafariで開き、上の手順でホーム画面に追加する

ファイルは1つだけです。記録はURLを開いた端末・ブラウザごとに保存されます（今このページで付けた記録は、GitHub Pages版には自動では移りません）。

記録はこの端末内にのみ保存されます。ブラウザのデータを消すと記録も消えるので、月末にCSVやPDFで残すのがおすすめです。

勤務を追加

時刻は最初は空白です。数字キーボードで直接入力してください（「9:30」でも「930」でもOK、欄から離れると 09:30 の形に整います）。出勤・退勤の両方が必要です。

設定の時給がそのまま記録されます。

休憩は空白のまま保存すると0分として計算します。退勤が出勤より早い時刻の場合は、翌日まで働いたものとして計算します（夜勤など）。
